Google Maps mode (needs your key)

With your own Google Maps key this page adds Google's 3D view, plus photos, ratings and exact addresses when you tap a place. Google charges each map load and place lookup to your Cloud credits.

  1. Open console.cloud.google.com and pick or create a project with billing on.
  2. Enable three APIs: Maps JavaScript API, Places API (New) and Map Tiles API.
  3. Go to Credentials, create an API key, and restrict it to those three APIs.
  4. Paste the key below. It is saved only in this browser.

Pins marked "area pin" show the neighbourhood, not the exact door. Map data: Esri World Imagery, OpenStreetMap contributors, and terrain tiles from Mapzen on AWS.
